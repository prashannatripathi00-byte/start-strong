## Improvement Record Template

| Field | Description |
|---|---|
| Observation | What the analytics data showed |
| Metric and value | The specific GA4 metric that triggered the review |
| Hypothesis | What might be causing the issue |
| Change made | Specific change to content, design or structure |
| Date of change | Date the change was implemented |
| Post-change result | Data collected 7–14 days after the change |
| Conclusion | Was the change effective? What was learned? |
