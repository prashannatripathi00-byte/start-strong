## Long-Term Vision

A fully developed Start Strong could evolve to include:

- A dedicated 5K training programme
- An events calendar for local running events
- A running routes feature (community-submitted)
- A "Start Strong community" discussion area
- Running challenge campaigns with social media tie-ins
- Partnerships with sports physio clinics for injury content

---

## Limitations to Acknowledge

Any future development plan should acknowledge current limitations:

1. **Traffic volume:** Early-stage sites typically have limited traffic, which limits the reliability of analytics insights
2. **Data collection time:** Assessment periods may not allow enough time for full SEO performance to become visible
3. **Resources:** Single-person projects have content production constraints
4. **Technical scope:** GitHub Pages limits server-side functionality (no forms, no user accounts)
5. **Social media:** Building genuine social followings takes time that may exceed an assessment timeline
