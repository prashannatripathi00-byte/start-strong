## Start Strong — Development Log

This document records the development history of the Start Strong website project.

---

## Project Initialisation

**Date:** 21 October 2026  
**Phase:** Full project build

### Initial Setup

- Project directory created
- Technology stack confirmed: Astro 4 + Custom CSS + GitHub Pages
- Project structure defined based on Astro conventions
- `package.json` configured with Astro 4 and @astrojs/sitemap dependencies

### Architecture Decisions

| Decision | Rationale |
|---|---|
| Astro static site generator | Fast, SEO-friendly HTML; no server required for GitHub Pages; content collections for blog |
| Custom CSS (no Tailwind or Bootstrap) | Full brand control; smaller output; no utility class bloat |
| Markdown content collections | Easy to author and maintain articles; no code changes needed to publish |
| GitHub Pages + GitHub Actions | Free hosting; automated deployment on every push |
| GA4 with consent banner | Compliant analytics; required for assessment criterion 5 |
| No framework JavaScript | Minimal JS bundle; Astro ships zero JS by default unless needed |

## Phase 2 — Core Components and Layouts

**Files created:**
- `src/styles/global.css` — complete design system (CSS custom properties, typography, buttons, cards, utilities)
- `src/layouts/BaseLayout.astro` — HTML shell with full SEO meta, GA4 placeholder, cookie consent
- `src/layouts/ArticleLayout.astro` — article wrapper with reading progress, breadcrumb, sidebar, related posts
- `src/components/Header.astro` — sticky nav with mobile hamburger, accessibility support
- `src/components/Footer.astro` — multi-column footer with social links
- `src/components/CookieConsent.astro` — GDPR-compliant consent banner, consent-gated GA4 loading
- `src/components/SocialShare.astro` — Facebook, Twitter, copy-link share buttons
- `src/components/ArticleCard.astro` — reusable blog card with GA4 tracking
- `src/components/CTASection.astro` — configurable call-to-action section
- `src/utils/analytics.ts` — GA4 event tracking utility functions

**Design decisions:**
- Colour palette: Dark (#172025), Orange (#FF6B35), Ivory (#F8F7F3)
- Typography: Poppins (headings) + Inter (body) via Google Fonts
- Cookie consent banner — analytics only loads after visitor accepts
- Reading progress bar on article pages
- Scroll depth tracking at 25/50/75/100%
