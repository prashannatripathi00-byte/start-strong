# 05 — SEO Strategy

## SEO Overview

Search engine optimisation is the primary traffic acquisition channel for Start Strong. Every page is optimised for discoverability, crawlability and relevance to beginner runner search intent.

> **Important:** No keyword research data (search volumes, difficulty scores, ranking positions) is presented here because the website has not yet been live long enough to generate real data. These will be populated once the site is indexed and Search Console data is available.

| Common running mistakes | Informational | Blog article |

| How to stay motivated running | Informational | Blog article |
| What to wear running | Commercial investigation | Running Gear |
| Running warm up routine | Informational | Start Running |

### Keyword Intent Explanation

- **Informational:** User wants to learn something. Content should educate thoroughly.
- **Commercial investigation:** User is considering a purchase and researching options. Content should be honest, comparison-focused and include appropriate disclosures.
- **Navigational:** User is looking for a specific resource (e.g. "couch to 5k plan"). Content should be the definitive resource on that specific topic.

## Structured Data

JSON-LD `Article` schema is implemented on all blog article pages. It includes:
- `headline`, `description`
- `datePublished`, `dateModified`
- `author`, `publisher`
- `mainEntityOfPage`

This supports rich snippets in search results (publication date, article type).

## Content SEO Strategy

Each article is written to address a single, specific search intent comprehensively. Key content SEO practices:

1. **Primary keyword in H1** — naturally, not forced
2. **Primary keyword in first paragraph** — contextual usage
3. **Related terms used naturally** — synonyms and semantic variations
4. **Clear, logical heading structure** — H2 for main sections, H3 for subsections
5. **Answer the question directly** — early in the article for featured snippet potential
6. **Sufficient depth** — articles are genuinely comprehensive, not padded
7. **Internal links at natural points** — not forced keyword links
